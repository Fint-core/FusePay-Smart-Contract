# Mainnet Deployments

Contract IDs deployed to Stellar Mainnet are stored here.

⚠️ Mainnet deployments are irreversible and manage real funds.
All contract IDs listed here should be verified on
[Stellar Expert](https://stellar.expert/explorer/public) before use.

Do NOT deploy to mainnet without:
1. A completed security audit
2. Community review and approval
3. Multisig governance in place
